# IronRise: система тренировок для новичков

> Версия 0.1 от 12 ноября 2026, черновик для согласования.
> **Это не медицинская рекомендация.** Числа ниже — разумные стартовые значения из общих принципов силовой подготовки новичков. Перед бетой документ, нормативы силы и тексты советов должен проверить тренер или спортивный врач (см. раздел 10).

## 1. Цель и принципы

Аудитория — люди 18–24 лет, которые бросают зал через 4–6 недель. Значит, главная метрика — **регулярность**, а не рекорды. Отсюда принципы:

1. **Лучше недогрузить, чем перегрузить.** Первые недели тренировка должна заканчиваться с ощущением «мог бы ещё». Боль и разбитость на следующий день — главная причина бросить.
2. **Простое и знакомое.** 4–5 базовых движений, а не 12 упражнений по видео.
3. **Видимый прогресс каждую неделю.** Вес или повторы растут маленькими шагами, приложение это показывает.
4. **Игра не толкает к лишнему весу.** Опыт героя зависит от подходов и пульса, а не от веса на штанге. Вес влияет только на «уровень силы» в профиле, и рост этого уровня ограничен безопасными шагами.
5. **Отдых — часть программы.** Между тренировками одной группы мышц минимум 48 часов.

## 2. Первый запуск: анкета вместо теста на максимум

Новичку **нельзя** предлагать проверить максимальный вес: это опасно и демотивирует. Вместо этого:

**Анкета (уже частично есть в онбординге):** пол, рост, вес, возраст, опыт (никогда / пробовал и бросал / тренируюсь), цель, формат (3/4/5 раз в неделю).

**Новое в анкете:**
- **Где тренируешься:** зал / дома с гантелями / дома без инвентаря. Определяет набор упражнений.
- **Проверка здоровья (3 вопроса в духе PAR-Q):** боль в груди при нагрузке, головокружения или потери сознания, травмы суставов или спины за последний год. Хотя бы одно «да» — приложение советует сначала обсудить тренировки с врачом и не начинает программу без отметки «врач разрешил / понимаю риск».

**Две калибровочные недели.** В каждом упражнении пользователь сам подбирает вес, с которым делает 12 повторов и чувствует, что **мог бы ещё 3** («3 повтора в запасе»). Приложение подсказывает: «Начни с пустого грифа / лёгких гантелей и добавляй, пока 12 повторов не станут ощутимыми». Эти веса — точка отсчёта для прогрессии и оценки силы.

## 3. Оценка силы

### 3.1 Расчётный максимум

Для каждого подхода с 3–12 повторами считаем расчётный разовый максимум (e1RM) по формуле Эпли:

```
e1RM = вес × (1 + повторы / 30)
```

Подходы больше 12 повторов в оценку не идут (формула там неточна). Лучший e1RM за последние 4 недели — текущая сила в упражнении.

### 3.2 Сила относительно веса тела

`относительная сила = e1RM / вес тела`. Сравниваем с нормативами для пола по ключевым движениям: присед, жим лёжа, тяга (верхнего блока или румынская), жим над головой.

| Уровень силы | Присед, ×вес тела (м / ж) | Жим лёжа (м / ж) | Тяга верхнего блока (м / ж) |
|---|---|---|---|
| 1. Старт | < 0,75 / < 0,5 | < 0,5 / < 0,3 | < 0,5 / < 0,35 |
| 2. Новичок | 0,75 / 0,5 | 0,5 / 0,3 | 0,5 / 0,35 |
| 3. Любитель | 1,25 / 0,85 | 0,85 / 0,5 | 0,8 / 0,55 |
| 4. Опытный | 1,75 / 1,25 | 1,25 / 0,75 | 1,1 / 0,8 |
| 5. Сильный | 2,25 / 1,6 | 1,6 / 1,0 | 1,4 / 1,0 |

> **Числа — ориентир для черновика, требуют проверки специалистом.** Возраст пока не учитываем: аудитория 18–24.

Для упражнений с собственным весом (отжимания, подтягивания, приседания без веса) — уровни по максимуму повторов в подходе (например, отжимания: <5 / 5–14 / 15–29 / 30–44 / 45+). Тоже на проверку.

### 3.3 Как это показываем

- В профиле игрока: «Сила: Новичок → Любитель» по каждому движению и общий уровень (среднее по движениям, которые человек делает).
- **Без сравнения с другими людьми** на первых этапах: только «ты месяц назад → ты сейчас».

## 4. Программы

Программа — это данные, а не код: список дней, в каждом — упражнения с подходами, диапазоном повторов и «повторами в запасе». Админ может менять программы без релиза.

### 4.1 Фаза 1 «Старт» — недели 1–4, для всех форматов

3 тренировки в неделю, всё тело, чередуются дни **А** и **Б**:

| День А | День Б |
|---|---|
| Приседания (или жим ногами) | Румынская тяга (или гиперэкстензия) |
| Жим лёжа (дома — отжимания) | Жим гантелей сидя (дома — отжимания с узкой постановкой) |
| Тяга верхнего блока (дома — тяга гантели в наклоне) | Тяга гантели в наклоне (дома — тяга резины / гантели) |
| Планка | Выпады |

- **2 подхода × 10–12 повторов, 3 в запасе.** Отдых 90 секунд (как сейчас).
- Около 30–40 минут на тренировку.
- Пользователь, выбравший формат 4 или 5 раз в неделю, в первой фазе всё равно получает 3 силовые тренировки, а дополнительные дни — лёгкое кардио. Объяснение в приложении: «Первый месяц важнее привыкнуть, чем выложиться».

### 4.2 Фаза 2 «База» — недели 5–12

- **3 подхода × 8–12 повторов, 2 в запасе.**
- По формату: 3 раза — фулбоди А/Б, 4 раза — верх/низ, 5 раз — верх/низ + день отстающей части.
- Появляется **одно точечное упражнение** в конце тренировки — на отстающую часть тела из игрового баланса (ТЗ 4.2). Так игровая подсказка «отстают ноги» превращается в конкретное упражнение в плане.

### 4.3 Фаза 3 «Рост» — после 12 недель

- Диапазоны 6–10 для базовых упражнений, 10–15 для точечных.
- 1–2 точечных упражнения на отстающие части.
- Раз в 6–8 недель — разгрузочная неделя (вес −10%, подходов вдвое меньше).

## 5. Прогрессия нагрузки: двойная прогрессия

Для каждого упражнения программа хранит рабочий вес.

1. Если **во всех подходах** сделан верх диапазона повторов (например, 12 из 10–12) и человек отметил, что запас был, — **на следующей тренировке вес растёт**:
   - упражнения на ноги и тяги: **+5 кг** (до 40 кг — +2,5 кг);
   - жимы и упражнения на руки: **+2,5 кг** (гантели — до ближайшей доступной: +1–2 кг);
   - упражнения с весом тела: +2 повтора к цели, затем усложнение (отжимания → с ногами на скамье).
2. Если повторы в диапазоне — вес тот же, добиваем повторы.
3. Если **два раза подряд** не дотянул до низа диапазона — вес не растёт, приложение спрашивает про самочувствие.
4. **Три раза подряд** — вес −10% («откат»), это нормально и так и объясняется.

После тренировки приложение показывает: «В следующий раз: присед 42,5 кг × 10–12».

## 6. Безопасность

- **Самочувствие после тренировки** (одно касание): «нормально / тяжело / что-то болит».
  - «Тяжело» два раза подряд — следующую тренировку облегчаем (−1 подход).
  - «Болит» — спрашиваем где; упражнения на эту зону заменяются щадящими на неделю, совет обратиться к врачу при повторении. Приложение не ставит диагнозов.
- **Без отказа.** Новичкам никогда не предлагаем «до отказа».
- **Потолок объёма в фазе 1:** не больше 10 подходов на группу мышц в неделю. Сверх плана опыт идёт, но приложение мягко отмечает «это сверх программы».
- **Рост рабочего веса не больше чем на 20%** e1RM за раз (антифрод из ТЗ 4.4, который здесь становится осмысленным): подход с весом сильно выше прошлого максимума не повышает уровень силы, пока его не повторят на следующей тренировке.
- Минимум 48 часов между тренировками одной группы мышц; в фазе 1 это гарантирует чередование А/Б.

## 7. Связь с игрой

- **Опыт героя не меняется:** подходы × доли нагрузки × баланс × пульс (ТЗ 4.1). Программа не обязательна — можно тренироваться свободно.
- **Бонус за план:** тренировка, выполненная по плану (все запланированные упражнения), даёт +20% монет. Монеты, а не опыт, чтобы не создавать давления на силу героя.
- **Уровень силы** из раздела 3 виден в профиле игрока и даёт достижения («Присед с весом тела», «Первые 10 отжиманий») — за них открываются готовые аватарки профиля.
- **Баланс тела** из игры выбирает точечные упражнения в фазах 2–3.

## 8. Как это выглядит в приложении

- **Главная:** «Сегодня: Тренировка А · 4 упражнения · ~35 минут» вместо пустой кнопки «Начать тренировку». Если день отдыха — «Отдых. Следующая: Тренировка Б, четверг».
- **Экран тренировки:** упражнения из плана уже добавлены, в каждом подставлен рабочий вес и цель «10–12 повторов». После последнего подхода — вопрос «Был запас?» (да / впритык).
- **Итог тренировки:** блок «В следующий раз» с новыми весами и отметка, если сработало правило отката.
- **Профиль игрока:** уровни силы по движениям, график e1RM по каждому упражнению.
- **Свободная тренировка** остаётся: кнопка «Без плана».

## 10. Что нужно от специалиста

1. Проверить нормативы силы (раздел 3.2) и упражнения с весом тела.
2. Проверить программы фаз 1–3 и замены для тренировок дома.
3. Проверить шаги прогрессии и правило отката.
4. Вопросы анкеты здоровья и тексты про боль.
5. Позже — материалы для «совета дня».

## 11. Порядок реализации

1. **Фаза 1 целиком:** анкета (место тренировок, здоровье), программа «Старт» А/Б, план на главной, предзаполненная тренировка, двойная прогрессия, «был запас?», блок «в следующий раз». Тесты расчётов.
2. **Оценка силы:** e1RM, уровни, профиль игрока со статистикой.
3. **Самочувствие и безопасность:** вопрос после тренировки, облегчение, замена упражнений.
4. **Фазы 2–3:** точечные упражнения по балансу, форматы 4–5 раз, разгрузка.
5. Синхронизация программы с сервером.

## 13. Старт новичка: цели, «2 раза в неделю», входная тренировка (проект от 16.11.2026)

> Бэклог: п. 100, 116, 117. Роадмап: недели 3–4. **На согласовании** — ответы на вопросы в 13.6.

### 13.1 Несколько целей

Сейчас цель одна из четырёх и почти ни на что не влияет. Делаем так:

- Игрок выбирает **главную цель** и, по желанию, **ещё одну-две**. Главная задаёт путь
  тренировок (13.5), дополнительные — акценты в советах и напоминаниях.
- Цели: **Набрать массу**, **Стать сильнее**, **Похудеть**, **Выносливость** (новая),
  **Тренироваться регулярно**.
- Сменить цели можно в настройках в любой момент (план перестраивается со следующей
  тренировки).
- Сервер: поле `goal` остаётся главной целью (старые клиенты не ломаются), добавляется
  `goals text[]` — миграция руками.

### 13.2 Формат «2 раза в неделю»

- Новый формат **«Минимум»**: 2 тренировки в неделю, всё тело за раз (дни А и Б), например
  Пн и Чт. В описании честно: «чтобы начать и не бросить; для заметного роста лучше 3».
- Минимум дней в неделю — **2** вместо 3 (приложение и сервер, `minTrainingDaysPerWeek`,
  `MIN_TRAINING_DAYS`). Правило серии то же: допустимый отдых = самый длинный перерыв
  по графику. При Пн/Чт это 3 дня — серия по-прежнему не бесконечная, а «раз в неделю»
  по-прежнему нельзя.
- Награды за серию не меняются: они за дни, а не за тренировки.
- Объём: у «Минимума» на тренировку на 1 упражнение больше (недельная норма подходов
  делится на 2 дня), но не больше потолка дня (`daySets`).

### 13.3 Входная тренировка

Не тест на максимум (раздел 2 остаётся в силе), а **короткая домашняя проверка — 10 минут**,
без инвентаря, сразу после создания героя (можно отложить на потом, предлагаем на главной,
пока не пройдена).

| # | Упражнение | Что записываем | Правило остановки |
|---|---|---|---|
| 1 | Отжимания (или с колен — выбор) | повторы | первый повтор с плохой техникой |
| 2 | Приседания без веса за 60 с | повторы | кончилось время или техника |
| 3 | Скручивания за 60 с | повторы | кончилось время; лопатки отрываются, поясница прижата |
| 4 | Бёрпи за 60 с | повторы | кончилось время или техника |
| 5 | Планка | секунды | таз провис или 120 с |
| 6 | Подтягивания — **если есть турник** | повторы | рывки или неполная амплитуда |

Отдых 90 с между упражнениями (после бёрпи — 2 минуты, пульс высокий). Всего ~12–14 минут.
Бёрпи — последним из «на время» и с пометкой «прыжок можно заменить подъёмом на носки»: это
самое тяжёлое упражнение для неподготовленного сердца. Перед стартом — вопросы о здоровье (PAR-Q) уже пройдены в
онбординге; при «да» на любой — входную тренировку не предлагаем.

**Что из неё следует:**

- **Уровень подготовки** (новичок / средний / опытный) по таблице 13.4 вместо самооценки
  из анкеты. Анкета остаётся запасным вариантом, если тест пропущен.
- **Ступени лесенок** (`exercise_ladder.dart`): отжимания с колен или классика, присед с весом
  тела или гоблет, негативы или подтягивания.
- **Место** — как выбрал игрок, зал новичкам не закрываем (решено 16.11):
  - **дома** — упражнения без инвентаря;
  - **в зале новичку** — те же базовые упражнения без инвентаря плюс 2–3 упражнения с
    инвентарём и небольшим весом: сгибания с гантелями, **гравитрон** (подтягивания с
    противовесом — добавить в базу), тяга верхнего блока, жим в тренажёре сидя, жим
    ногами. Вес — стартовый из базы, «12 повторов и 3 в запасе» (раздел 2);
  - **в зале среднему и опытному** — обычная программа по уровню.
- **Награда**: +50 монет и запись «Входная тренировка» в журнал; опыт — как за обычную
  тренировку с 4 подходами (без часов — V = 0,5, как везде).
- **Повтор через 4 недели** — «Проверим, насколько ты вырос?»: те же упражнения, сравнение
  «было → стало» (карточка, которой можно поделиться).

### 13.4 Уровень по входной тренировке

Ориентир для черновика, **на проверку специалисту** (раздел 10):

| | Новичок | Средний | Опытный |
|---|---|---|---|
| Отжимания, м | < 10 | 10–29 | 30+ |
| Отжимания, ж | < 5 (или с колен) | 5–19 | 20+ |
| Приседания за 60 с | < 25 | 25–39 | 40+ |
| Скручивания за 60 с | < 30 | 30–54 | 55+ |
| Бёрпи за 60 с | < 19 | 19–29 | 30+ |
| Планка | < 45 с | 45–89 с | 90+ с |
| Подтягивания (если есть), м / ж | 0 / 0 | 1–7 / 1–3 | 8+ / 4+ |

Уровень — по большинству упражнений; при равенстве — ниже (лучше недогрузить).
Пороги скручиваний и бёрпи — от пользователя (16.11): 55+ скручиваний и 30+ бёрпи — отлично,
меньше 30 скручиваний и 15–18 бёрпи — маловато.

### 13.5 Через месяц — больше инвентаря (и путь цели, п. 117)

- Домашним игрокам через ~4 недели, если по двойной прогрессии упёрлись в верх лесенки
  (например, 3 × 20 отжиманий) или повторный тест дал «средний» — карточка на главной:
  «Дома ты вырос. Готов к гантелям или залу?» → смена места тренировок в настройках
  (`Где тренируешься`), лесенки переходят на ступени с весом.
- **Путь цели** (п. 117, неделя 4) — отдельным разделом: пул упражнений и правила подбора
  для каждой главной цели (похудеть — больше энергоёмких и кардио, взвешивание чаще;
  сила — 3–6 повторов в базовых раньше; выносливость — круговые и кардио; масса —
  больше объёма; регулярность — минимум сложности, максимум удовольствия).

### 13.6 Решения (16.11.2026)

1. **Цели:** главная + **до 2 дополнительных**.
2. **«Выносливость»** — добавляем; в её пул — больше упражнений «на дыхалку»: бёрпи,
   скалолаз, прыжки, джампинг-джек, интервальное кардио, круговые тренировки (п. 117).
3. **Входная тренировка:** можно пропустить, но **настаиваем** — экран сразу после
   создания героя, карточка на главной до прохождения, напоминание через день, при пропуске —
   «уровень по анкете, план может быть не по силам».
4. **+50 монет** за входную и за повторную через месяц. Результаты обеих — в статистику
   (политика уже покрывает статистику беты): так видно, как приложение улучшает форму, а
   игроку — карточка «было → стало».
5. **«Минимум» — загрузка + разгрузка** (идея пользователя, уточнено):
   - неделя: загрузка → разгрузка → отдых → загрузка → разгрузка → отдых, отдых
     (например, Пн-Вт-Чт-Пт). Тяжёлых тренировок — две, как обещает формат;
   - **загрузка** — полная тренировка (зал или дом), всё тело;
   - **разгрузка (активное восстановление)**, 10–15 минут дома: растяжка мышц, которые работали
     в загрузку, лёгкое кардио (ходьба, велосипед), дыхание, кор (то, что не грузили).
     Не отжимания на грудь после дня груди — ей нужно восстановиться;
   - в разгрузку — **опрос самочувствия**: как ощущения, что болит (часть тела из
     загрузки) → облегчение или замена в следующей загрузке (п. 81);
   - разгрузка — свой вид активности: продлевает серию, даёт немного опыта и монет (как шаги
     в день отдыха), не занимает лимит «одна силовая в день»;
   - правило серии общее: отдых = самый длинный перерыв по графику (при Пн-Вт-Чт-Пт — 2 дня).

### 13.7 Порядок реализации

1. Цели (главная + 2), «Выносливость» — приложение, сервер (`goals text[]`, миграция).
2. Формат «Минимум»: дни загрузки и разгрузки, тренировка-разгрузка с опросом, минимум
   дней — 2 (приложение и сервер).
3. Входная тренировка + повторная через 4 недели, уровень и ступени по ней, +50 монет.
4. Гравитрон в базу; стартовая программа в зале для новичков.
5. Путь цели (п. 117) — следующим этапом.

## 14. Стиль и дни — выбирает игрок, раскладку делает программа (16.11.2026, п. 132)

Игрок выбирает **стиль** и **любые дни** (2–6 в неделю, минимум 1 день отдыха). Дни программы
идут по кругу (следующая тренировка — следующий день раскладки, независимо от дня недели).

| Стиль | Раскладка по кругу | Когда мышцы перекрываются |
|---|---|---|
| Всё тело | А → Б | в соседние дни — тогда программа сама берёт верх/низ |
| Верх / низ | Верх → Низ | никогда: соседние дни — разные половины тела |
| Сплит | Спина и бицепс → Грудь и трицепс → Ноги и плечи | никогда |
| Подбери сам | 2 дня — всё тело; 3 — сплит (новичку при днях через день — всё тело); 4 — верх/низ; 5–6 — сплит | никогда |
| Минимум | Всё тело + день восстановления после | никогда |

- **Фаза «Старт» (первые 4 недели):** всё тело А/Б при днях через день, верх/низ — если есть
  соседние дни. Меньше подходов, больше запаса — как раньше.
- **Недельная норма подходов** делится на число тренировок (`_distributeSets`), поэтому
  при 6 днях каждая тренировка короче, при 2 — длиннее (в пределах `daySets`).
- При выборе дней приложение предупреждает: «всё тело в соседние дни — возьмём верх/низ».
- Минимум дней — **2** для всех стилей (приложение и сервер).

## 15. Свой путь у каждой цели (16.11.2026, п. 117)

Главная цель меняет план после фазы «Старт» (в «Старте» — только отдых; сам «Старт»
одинаков для всех ради безопасности). Код — `app/lib/game/goal_path.dart`.

| Цель | Базовые / изоляция, повторы | Запас | Отдых | Упражнений | Финишер |
|---|---|---|---|---|---|
| Набрать массу | 8–12 / 10–15 | по уровню | 90 с | по уровню | — |
| Стать сильнее | 4–6 (новичку 6–8) / 8–12 | по уровню | 150 с | −1 | — |
| Похудеть | 10–15 / 12–15 | по уровню | 60 с | по уровню | да |
| Стать выносливее | 12–20 / 15–20 | по уровню | 45 с | по уровню | да |
| Тренироваться регулярно | 10–12 / 12–15 | +1 | 90 с | −1 | — |

- **Финишер «на дыхалку»** — последнее упражнение дня, 2 подхода: новичку «звёздочка» и
  скалолаз (30–45 с), остальным бёрпи, приседания с выпрыгиванием, скалолаз (10–15 раз).
  Упражнения — в базе с движением `conditioning`, в рекомендации «что подкачать» не идут.
- **Дополнительные цели** — акценты: «похудеть» среди них — взвешивание раз в 2 дня, а не в 3.
- Пороги и диапазоны — ориентир, на проверку специалисту (раздел 10).
