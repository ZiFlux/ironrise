# Заявка на изобретение: черновик

Черновик документов заявки в Роспатент на «Способ и систему учёта физической нагрузки с верификацией по данным носимого датчика ЧСС и формированием графической модели тела». Подготовлен 12.11.2026 по коду IronRise, сверен с версией 1.1.0 13.11.2026 (антифрод, прогрессия, мышцы, стартовый образ). **Перед подачей нужна проверка патентного поверенного**: формулировки формулы и описания влияют на объём охраны, и исправить их после подачи почти нельзя.

## Что в папке

| Файл | Документ заявки |
|---|---|
| `01_описание.md` | Описание изобретения: область техники, уровень техники, сущность, чертежи, осуществление, примеры |
| `02_формула.md` | Формула: независимые п. 1 (способ) и п. 13 (система), зависимые пп. 2–12 |
| `03_реферат.md` | Реферат, 953 знака (лимит 1000) |
| `фиг1_система`, `фиг2_алгоритм`, `фиг3_пульс` (.svg и .png) | Чертежи: схема системы, блок-схема, пример пульса |
| `IronRise_заявка_изобретение.docx` | Всё вместе для подачи и для поверенного |

Заявление о выдаче патента заполняется прямо в форме подачи на сайте ФИПС: заявитель, автор, адреса, название. Отдельный файл для него не нужен.

## Что охраняем и почему так

Программы для ЭВМ и правила игр сами по себе изобретениями не являются (ГК РФ, ст. 1350, п. 5). Поэтому заявка построена вокруг **технического результата**: достоверность учёта нагрузки повышается за счёт того, что вручную введённые подходы автоматически проверяются измерениями датчика ЧСС. Игровая часть (уровни, сила, дуэли, аватар) входит только как следствие и в зависимые пункты. Если эксперт сочтёт формулу «методом обработки информации» без технического результата, поверенный сможет усилить техническую часть: носимое устройство, датчик, передача в реальном времени, проверка на сервере.

## Риски, которые стоит обсудить с поверенным

1. **Новизна.** Публичная бета, публикации, видео и доклады до подачи могут помешать новизне. В РФ есть льгота: раскрытие самим автором не вредит, если заявку подали в течение 6 месяцев (ГК РФ, ст. 1350, п. 3). Закрытая бета с ограниченным кругом тестеров обычно раскрытием не считается, но дату первого показа лучше записать.
2. **Изобретательский уровень.** Отдельные признаки известны: пульсовые зоны и формула Карвонена, игровые очки за тренировки. Новое — их сочетание: проверка силовых подходов по колебаниям пульса и темпу, коэффициент достоверности в начислении, модель тела из подтверждённой нагрузки по мышцам. Поверенный проведёт патентный поиск и, возможно, сузит п. 1.
3. **Пороги** (0,6, 15 уд/мин, 5 уд/мин, 45 с, 0,5, 600) в формуле названы «заданными», а конкретные значения есть только в описании как пример. Так их можно менять в продукте, не выходя за патент.
4. **Заявитель.** Патент получит тот, кто указан заявителем: вы как физлицо или будущее юрлицо (PLAN.md, раздел 7). Если позже будет юрлицо, права можно передать по договору.

## Порядок подачи

1. Показать папку поверенному и внести правки.
2. Подать электронно через сайт ФИПС (нужна электронная подпись или Госуслуги). За электронную подачу пошлина ниже. Актуальные суммы пошлин за подачу, экспертизу по существу и выдачу — в перечне пошлин на сайте Роспатента. Автору-физлицу положена скидка.
3. Формальная экспертиза — около 2 месяцев, экспертиза по существу — от 6–12 месяцев после ходатайства. Ходатайство об экспертизе можно подать сразу.
4. Параллельно, дешевле и быстрее: **свидетельство о регистрации программы для ЭВМ** (PLAN.md, раздел 8). Оно охраняет код, а не способ, зато его выдают без экспертизы по существу.
