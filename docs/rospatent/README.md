### Реферат

Программа предназначена для учёта силовых и кардиотренировок в игровой форме. Пользователь записывает подходы, а носимое устройство (часы Wear OS или Bluetooth-датчик) передаёт пульс. Сервер проверяет достоверность тренировки по пульсу и темпу подходов и начисляет опыт частям тела и мышцам героя-аватара, внешний вид которого меняется с прогрессом. Реализованы программы тренировок с прогрессией нагрузки, оценка силы, серия по графику, дуэли, недельные лиги, друзья, совместные тренировки, магазин косметики, push-уведомления. Область применения: фитнес и спорт. Состав: мобильное приложение для Android, приложение для часов Wear OS, серверное приложение (REST API, PostgreSQL).

## Файлы

- `IronRise_листинг.pdf` — исходный текст: первые и последние 25 листов полного листинга (327 листов, 24 840 строк). Начинается с игрового расчёта сервера (антифрод, опыт, прогрессия), заканчивается приложением для часов. Персональных данных в коде нет.
- `IronRise_экраны.pdf` — 9 экранов приложения на тестовом герое «Атлет».
- `screens/` — исходные скриншоты.

## Как пересобрать

1. Скриншоты (из папки `app`):
   `flutter test test/rospatent_screens_test.dart --update-goldens --dart-define=ENV=beta --dart-define=ROUTES=/onboarding,/,/workout,/duels,/rating,/profile,/profile/start-look,/shop,/profile/settings`
2. PDF (из корня, нужен `pip install pymupdf`): `python -I tools/rospatent_pdf.py`

Листинг собирается из текущего кода, поэтому перед подачей его стоит пересобрать.
