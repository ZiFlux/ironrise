### Реферат

Программа предназначена для учёта силовых и кардиотренировок в игровой форме. Пользователь записывает подходы, а носимое устройство (часы Wear OS или Bluetooth-датчик) передаёт пульс. Сервер проверяет достоверность тренировки по пульсу и темпу подходов и начисляет опыт частям тела и мышцам героя-аватара, внешний вид которого меняется с прогрессом. Программа подбирает тренировки по уровню подготовки (6–8 упражнений, недельная норма подходов на мышцу, силовые и разгрузочные дни), анализирует нагрузку и прогнозирует результаты, учитывает вес и состав тела. Реализованы серия по графику, дуэли, недельные лиги, друзья, совместные тренировки, магазин косметики, уведомления, плитка для часов и виджет. Область применения: фитнес и спорт. Состав: мобильное приложение для Android, приложение для часов Wear OS, серверное приложение (REST API, PostgreSQL).

## Файлы

- `IronRise_листинг.pdf` — исходный текст: первые и последние 25 листов полного листинга (502 листа, 38 145 строк). Начинается с игрового расчёта сервера (антифрод, опыт, прогрессия), заканчивается приложением для часов. Персональных данных в коде нет.
- `IronRise_экраны.pdf` — 9 экранов приложения на тестовом герое «Атлет» (с месяцем тренировок для экрана анализа).
- `screens/` — исходные скриншоты.

## Как пересобрать

1. Скриншоты (из папки `app`):
   `flutter test test/rospatent_screens_test.dart --update-goldens --dart-define=ENV=beta --dart-define=ROUTES=/onboarding,/,/workout,/workout/stats,/duels,/profile,/profile/start-look,/shop,/profile/settings`
   (в Git Bash — с `MSYS_NO_PATHCONV=1` впереди, иначе `/onboarding` превратится в путь Windows)
2. PDF (из корня, нужен `py -m pip install --user pymupdf`): `py tools/rospatent_pdf.py`

Листинг собирается из текущего кода, поэтому перед подачей его стоит пересобрать.
