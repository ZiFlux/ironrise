### Реферат

Программа для учёта силовых и кардиотренировок в игровой форме. Пользователь записывает подходы, носимое устройство (часы Wear OS или Bluetooth-датчик) передаёт пульс, также используются данные Health Connect: шаги, пульс, состав тела. Сервер проверяет достоверность тренировки по пульсу и темпу подходов и начисляет опыт частям тела и мышцам героя-аватара, внешний вид которого меняется с прогрессом. Программа подбирает тренировки по уровню подготовки с недельной нормой нагрузки на мышцы, силовыми и разгрузочными днями, анализирует нагрузку, прогнозирует результаты, ведёт вес и состав тела. Есть справочник упражнений с техникой, разминка, серия с наградами, дуэли, лиги, друзья, совместные тренировки, магазин косметики, уведомления, плитка и журнал на часах, виджет, запись в календарь. Область: фитнес и спорт. Состав: приложения для Android и Wear OS, сервер (REST API, PostgreSQL).

## Файлы

- `IronRise_листинг.pdf` — исходный текст: первые и последние 25 листов полного листинга (502 листа, 38 145 строк). Начинается с игрового расчёта сервера (антифрод, опыт, прогрессия), заканчивается приложением для часов. Персональных данных в коде нет.
- `IronRise_реферат.docx` и `.pdf` — реферат отдельным документом: название, тип ЭВМ, язык, ОС, объём и аннотация; автора и правообладателя вписать от руки. Собирается из этого README: `NODE_PATH=<папка с docx@9>/node_modules node tools/rospatent_abstract_docx.js` (PDF — «Сохранить как PDF» в Word).
- `IronRise_экраны.pdf` — 9 экранов приложения на тестовом герое «Атлет» (с месяцем тренировок для экрана анализа).
- `screens/` — исходные скриншоты.

## Как пересобрать

1. Скриншоты (из папки `app`):
   `flutter test test/rospatent_screens_test.dart --update-goldens --dart-define=ENV=beta --dart-define=ROUTES=/onboarding,/,/workout,/workout/stats,/duels,/profile,/profile/start-look,/shop,/profile/settings`
   (в Git Bash — с `MSYS_NO_PATHCONV=1` впереди, иначе `/onboarding` превратится в путь Windows)
2. PDF (из корня, нужен `py -m pip install --user pymupdf`): `py tools/rospatent_pdf.py`

Листинг собирается из текущего кода, поэтому перед подачей его стоит пересобрать.
