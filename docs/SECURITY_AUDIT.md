# Аудит безопасности сервера (п. 130), 17.11.2026

Проверено по OWASP API Security Top 10 по коду `server/src`. Прод и данные игроков не читались.

## Что в порядке
- **Вход (API2):** `AuthGuard` на всех контроллерах с данными игрока; без входа — только
  регистрация/вход/refresh, политика, health, приём журнала ошибок и страница админки.
- **Чужие данные (API1, BOLA):** профиль игрока — только другу (`users/:id/profile`), «кулак» в
  ленте — только на свои и друзей события, принять заявку — только адресованную тебе, лига друзей
  отдаёт `friendId` только друзьям; id в путях — `ParseUUIDPipe`, лига — 0–5, ауры и награды — enum.
- **Валидация (API3/API8):** Zod с лимитами на всех телах запросов (подходы, пульс до 5 000 точек,
  журнал до 200 записей по 4–8 КБ).
- **Начисления и гонки (API6):** монеты, покупки, ник, шаги, совет дня, входная тренировка,
  тренировки, ауры, бои — транзакция + `SELECT … FOR UPDATE` по профилю; тренировки идемпотентны
  по `clientId`; лимиты «раз в день/неделю» проверяются под блокировкой.
- **Числа считает сервер:** опыт, монеты, сезон, лига, достоверность пульса, нормы ауры.
- **Лимиты частоты (API4):** 600/мин на адрес; вход/регистрация/удаление — 10 за 15 мин на адрес
  и 5 на e-mail; админка — 60/мин; адрес клиента — последний в X-Forwarded-For (Caddy).
- **Dev-инструменты (API9):** `DevController` подключается только при `DEV_TOOLS=true`
  (локальный compose); на проде его нет.
- **Сеть:** наружу только 80/443 (Caddy); Postgres доступен лишь внутри docker-сети.
- **Админка:** ключ сравнивается за постоянное время, без ключа страница — 404; все действия
  в журнале `AdminAction`.

## Исправлено в этом аудите
- **Журнал ошибок без входа** можно было использовать, чтобы забивать базу (600 запросов/мин ×
  200 записей). Теперь — 20 запросов в минуту с адреса (`logsByIp`).
- **Поиск игроков** — 60 запросов в минуту с адреса (`searchByIp`), против перебора ников.
- Решение по лимитам вынесено в `rateLimitVerdict` и покрыто тестами.

## Принятые риски (низкие)
- **Совет дня:** число верных ответов присылает телефон — можно получить максимум монет за совет
  (несколько десятков в день). На силу не влияет.
- **Достижения «гайд» и «часы»:** вещь выдаётся по слову телефона, один раз. Только косметика.
- **Лимиты частоты в памяти процесса:** при нескольких копиях API их надо вынести в Redis/Postgres.
